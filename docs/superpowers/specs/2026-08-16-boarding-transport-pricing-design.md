# 犬寄养与寄养／洗护接送价格同步设计

日期：2026-08-16

## 目标

把本次经营者确认的犬寄养予定价和寄养／洗护宠物接送价写入网站的统一价源，并同步到公开页面、只读费用计算器、生成文件和客服知识。任何公开入口不得继续使用此前讨论过但已被替代的“10km 内单程统一 ¥3,300”方案。

犬寄养继续保持准备中和停止接单。本轮只更新预计价格，不开放犬预约、犬 LINE 接单、犬结构化 Offer 或犬日历写入。

## 冻结价格

### 犬寄养予定价

所有金额均为含税予定价格。

| 体重分类 | 价格 |
|---|---:|
| 小型犬（10kg 未满） | ¥5,000 / 1泊 |
| 中型犬（10kg 以上、20kg 未满） | ¥7,500 / 1泊 |
| 大型犬（20kg 以上） | ¥9,500 / 1泊 |

现行全动物长住折扣继续适用。示例：30晚按 20%OFF 后，中型犬为 ¥180,000，大型犬为 ¥228,000。

### 寄养／洗护宠物接送

距离是福楽ペット店铺到接送地址的单程距离；页面显示为含税参考价，最终距离与可接送性由店铺确认。

| 单程距离 | 单程一次 | 接走＋送回 |
|---|---:|---:|
| 3km以内 | ¥1,650 | ¥3,300 |
| 超过3km、5km以内 | ¥2,200 | ¥4,400 |
| 超过5km、10km以内 | ¥3,300 | ¥6,600 |
| 超过10km、20km以内 | LINE询价 | LINE询价 |
| 超过20km | 不提供接送 | 不提供接送 |

往返价是两次单程服务的合计。接送费独立于寄养和洗护费用，不参加长住折扣、福楽卒业猫折扣或其他优惠。

## 服务边界

新表只命名为“お預かり・ケア利用時のペット送迎”，适用于寄养和洗护服务中的员工宠物接送。

`guide/price.html` 现有的幼猫交付（空港交付、汽车交付）属于售出幼猫的交付服务，不套用新表，也不在本轮擅自修改其价格。新接送说明必须明确“子猫のお届けとは別料金”，防止客户和客服混淆。

网站聊天组件中的“最寄站接送”属于来店访客指引，不得改写成宠物接送承诺。

## 单一价源与数据流

`boarding-public-config.js` 继续作为人工维护的唯一价源：

1. 更新犬寄养三档价，但保留 `public:false`、`preparing:true`、`accepting:false`。
2. 新增结构化的寄养／洗护接送五档配置，包含距离边界、单程状态、往返状态和是否参与折扣。
3. `dog-services-projection.js` 从同一配置生成犬准备中投影；`dog-services-launch.json` 继续只表达未公开状态。
4. 静态生成器从接送配置生成寄养页和洗护页相同的价格表，避免两页手写数字漂移。
5. 费用计算器从同一接送配置提供距离档和单程／往返选择，并把确定价格作为独立行加入概算。
6. 客服知识生成器从同一配置输出犬予定价、接送五档、折扣边界和幼猫交付区分说明。

配置缺字段、距离档不连续、往返数字不等于两次单程、10–20km 不是询价或 20km 以上仍可接送时，测试和生成流程必须失败关闭。

## 页面与计算器

### 寄养页与洗护页

两页均展示同一日文接送表，包含：

- 店铺到接送地址的单程距离定义；
- 单程一次与接走＋送回两列；
- 10–20km 的 LINE 询价；
- 超过20km不提供接送；
- 接送费不参加折扣；
- 与幼猫交付费用分开。

犬准备中价格卡自动更新为 ¥5,000 / ¥7,500 / ¥9,500，停止接单提示保持醒目。

### 费用计算器

在现有动物、日期、特典与护理选择之后新增可选的“送迎”区：

- 默认“不使用送迎”，不改变现有概算。
- 客户选择距离档后，再选择“单程一次”或“接走＋送回”。
- 3km、3–5km、5–10km 档把准确接送费作为独立行加入合计，但不参与任何折扣。
- 10–20km 不加入虚构金额，结果改为“送迎费はLINE見積り”，并在复制给 LINE 的文本中保留选择。
- 超过20km 显示“不提供送迎”，不得把该选择计算为零元服务。
- 犬选择仍为只读予定概算；接送选择不得解除犬停止接单状态。

## 缓存、生成与发布安全

凡修改公开脚本，统一提升相关资源版本，确保 HTML、配置、计算器和投影同批更新。运行生成器后提交其确定性生成物；连续运行两次不得产生新增差异。

本轮代码变更不等于生产上线。合并、推送、Pages 发布、Worker/KV 写入仍分别遵循既有发布门。若客服 `kb:boarding` 需要写入生产，只允许更新该单一键，并在获得相应发布授权后执行；不得批量覆盖其他 Worker 知识键。

## 测试与验收

实现采用测试先行：

1. 先锁定犬三档新价、30晚示例和停止接单 gate。
2. 新增接送配置合同，锁定五档边界、三档数字、往返倍数、询价档、拒绝档和不参与折扣。
3. 锁定寄养页、洗护页、计算器与客服知识全部来自统一价源，并包含相同服务边界。
4. 验证费用计算器的无接送、三档定价、LINE询价、超过20km和犬停止接单状态。
5. 验证幼猫交付价与访客接送文案未被新表误改。
6. 运行专项测试、全量 Node 测试、生成器、`verify-generated`、SEO/GEO 审计和 `git diff --check`。
7. 本地检查寄养、洗护、计算器的桌面和手机布局、键盘操作、错误状态、复制文本与控制台。

## 明确不做

- 不开放犬接单，不改变犬服务地点或启动时间。
- 不修改猫、小动物寄养基础价或现有洗护项目价。
- 不修改幼猫交付价或访客最寄站指引。
- 不自动读取客户地址或调用地图计费；客户在计算器中选择距离档，店铺最终确认。
- 不把接送费纳入任何折扣。
